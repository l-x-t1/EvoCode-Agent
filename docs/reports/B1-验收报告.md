## 二、实现说明（关键技术点）

1. **幂等键**：`Idempotency-Key` → Redis `idem:task:{key}`（TTL 24h）。重放返回原任务；Redis 不可用时降级为无幂等并记日志（不阻塞主流程）。
2. **D5 补齐**：`get_current_user` 依赖解析为 `dev@evocode.local`（幂等创建），未来接真鉴权只换这一个依赖实现。
3. **diffs/tests**：从 `agent_execution_logs` 的 `code.diff.created`/`test.finished` 事件 payload 读取——符合既有事件溯源设计，**零迁移**。
4. **健康路径二选一**：后端补 `GET /api/v1/system/health` 别名（与 `/api/v1/health` 同实现），前端零改动。
5. **数据库影响：零**。无迁移、无 DDL、无删改；测试产生的数据为真实开发库数据（54 个任务来自集成测试，seed 追加 6 个演示任务，均保留）。
