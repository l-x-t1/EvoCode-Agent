## ⚠️ 按修订要求如实声明的事项

1. **Embedding Provider 已独立抽象**（`BaseEmbeddingProvider`：name/dim/embed_texts），不与主对话模型强绑定。`GLMEmbeddingProvider` 为 open.bigmodel.cn `/embeddings` 真实 HTTP 实现（OpenAI 兼容、dimensions 参数、错误映射），**但接口未经真实调用实测**（GLM_API_KEY 缺失）——本批以 httpx.MockTransport 契约测试覆盖请求构造/响应解析/错误映射；真实冒烟列为未完成项。修订要求「先核实实际模型服务支持的 Embedding 接口」在 key 就绪后执行。
2. **当前运行环境使用 HashingEmbeddingProvider 兜底**（字符 2-gram 哈希、确定性、L2 归一化）——**仅保证离线可用与可复现，不具备语义检索质量**，日志如实告警；Provider 选择逻辑：key 配置 → 自动切 GLM。
3. **向量库为 FileVectorStore**（JSON 持久化 + 原子写 + 余弦检索），选型依据：任务文档允许「Chroma 或其他适合的向量数据库」，MVP 单进程小语料下文件库足够且避免 chromadb 重依赖与数据库迁移（20 表无 RAG 存储，遵守「不擅自改库结构」）；Chroma 切换留接口（调用方签名不变）。Reranker 为接口预留（NoopReranker 默认，RRF 序即最终序）。
