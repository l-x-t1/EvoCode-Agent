## 1. 全局布局结构（AppShell）


Sidebar 分组（自上而下）：

## 3. 路由表

| Path | 页面组件 | 布局 | 动态段/查询参数 | 说明 |
| --- | --- | --- | --- | --- |
| `/` | `DashboardPage` | AppShell | `?range=7d\|14d\|30d` | 时间范围写入 URL，可分享 |
| `/workspace` | `WorkspacePage` | AppShell | `?task=<id>`（抽屉定位用） | 空态含新建任务输入与最近任务 |
| `/workspace/:taskId` | `WorkspacePage` | AppShell | `?run=<runId>` | 缺省加载该 Task 最近 Run；`?panel=plan\|artifacts` 控制右栏焦点 |
| `/skills` | `SkillCenterPage` | AppShell | `?queue=candidates`, `?category=`, `?status=` | 主从布局，列表态 |
| `/skills/:skillId` | `SkillCenterPage` | AppShell | `?tab=overview\|versions\|evolution\|evals` | 详情 tab 写入 URL |
| `/context` | `ContextCenterPage` | AppShell | `?session=<sessionId>`, `?tab=` | 未选 session 时用最近一个（Mock 标注） |
| `/context/:sessionId` | `ContextCenterPage` | AppShell | `?tab=window\|compress\|memory\|summaries` | |
| `/workflow` | `WorkflowPage` | AppShell | — | 需选择 Run 才显示图；无运行时显示模板视图/空态 |
| `/workflow/:runId` | `WorkflowPage` | AppShell | `?node=<nodeId>`, `?t=<回放秒>` | 选中节点与回放进度可深链 |
| `/evaluation` | `EvaluationPage` | AppShell | `?range=30d`, `?suite=` | |
| `/settings` | — | AppShell | — | `<Navigate to="/settings/models" replace>` |
| `/settings/models` | `SettingsPage` | AppShell | — | Settings 内部为页内二级导航（非嵌套路由），tab 写入 URL 便于深链 |
| `/settings/routing` `/settings/mcp` `/settings/permissions` `/settings/system` | `SettingsPage` | AppShell | — | 同上，四个子路径渲染对应面板 |
| `*` | `NotFoundPage` | AppShell | — | |

**约定**：
- 所有「页内 tab / 筛选 / 选中项」均写入 search params（`useSearchParams`），保证刷新、分享、后退一致。
- 动态实体 ID 一律用路由段而非仅 query（如 `/workspace/:taskId`），query 只放视图状态。
- 列表→详情跳转尽量带 `state`（列表行摘要数据）实现即时渲染，再用详情 API 校正（stale-while-revalidate 观感）。

## 6. 路由实现要点（供开发对齐）

```
src/app/router.tsx        createBrowserRouter + lazy() 按页面分包
src/app/routes/           每页一个 route 对象文件（element + loader 位置预留）
src/app/layouts/AppShell  顶层布局路由（Sidebar/TopBar/Outlet）
守卫：当前阶段无鉴权，预留 requireAuth 高阶包装（doc 07 P4 接入）
```

- 页面组件全部 `React.lazy` + 路由级 Suspense（骨架屏复用 `PageSkeleton`）。
- 路由切换动画由 `AppShell` 内 `<AnimatePresence>` 统一处理（150ms fade + 4px 上移，见 doc 03 动效规范）。
- 错误边界：路由级 `ErrorBoundary` 统一渲染 `ErrorState` 组件。
