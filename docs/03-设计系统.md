# 03 — UI Design System（设计系统）

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v0.1（设计阶段草案） |
| 实现载体 | Tailwind CSS + CSS Variables（shadcn/ui token 体系）+ Framer Motion 动效规范 |
| 字体 | Inter（拉丁）+ 系统中文回退；JetBrains Mono（代码/数字） |
| 图标 | lucide-react（唯一图标源，禁止 Emoji 充当图标） |

---

## 1. 设计原则

1. **深色专业工具感**：深蓝黑底色 + 低饱和面板分层，让紫色强调色与数据色成为视觉焦点；像 IDE / 专业 SaaS，不像营销页也不像传统后台。
2. **克制用色**：渐变只允许出现在极少处（主按钮 hover、状态脉冲），大面积区域一律纯色分层；每个屏幕同时出现的强调色 ≤ 2 种语义。
3. **层级靠亮度不靠描边**：背景 3 级亮度（base/surface/elevated）区分层级，边框仅 1px 低对比，阴影极轻。
4. **状态即信息**：running/waiting_approval/failed 等状态是产品核心信息，用统一的 `StatusDot`/`StatusBadge` 语言贯穿全部页面。
5. **数据优先**：数字一律 `tabular-nums` 等宽；图表遵守统一色板与空态；杜绝装饰性大色块。

## 2. 颜色系统（Dark 主题，HSL CSS Variables）

> 采用 shadcn/ui 变量命名，Tailwind 通过 `hsl(var(--...))` 映射。当前仅定义 Dark 主题；变量分层保证未来新增 Light 主题不改组件代码。

### 2.1 基础面（背景三层 + 边框）

| Token | HSL | 用途 |
| --- | --- | --- |
| `--background` | `228 28% 5%` | 页面最底层（深蓝黑） |
| `--surface` | `228 22% 8%` | 侧边栏、卡片默认底 |
| `--surface-elevated` | `227 20% 11%` | 弹层、悬浮卡、选中行 |
| `--hover` | `227 18% 14%` | 行/按钮 hover |
| `--border` | `226 14% 17%` | 默认边框 |
| `--border-strong` | `226 12% 24%` | 输入框/拖拽分隔等需要更清晰的边 |

### 2.2 文本

| Token | HSL | 用途 |
| --- | --- | --- |
| `--foreground` | `220 25% 95%` | 主文本 |
| `--foreground-secondary` | `220 12% 68%` | 次要文本、描述 |
| `--foreground-muted` | `220 10% 46%` | 占位符、时间戳、禁用 |

### 2.3 品牌与语义色

| Token | HSL | 用途 |
| --- | --- | --- |
| `--primary` | `258 88% 66%` | 主紫：主按钮、选中态、链接、Logo |
| `--primary-soft` | `258 88% 66% / 12%` | 紫色 12% 透明底（选中行、tag 底） |
| `--accent` | `217 91% 62%` | 辅助蓝：次强调、图表主系列、进行中 |
| `--success` | `152 55% 45%` | completed / 测试通过 |
| `--warning` | `38 90% 56%` | waiting_approval / 阈值告警 |
| `--danger` | `352 74% 58%` | failed / 危险操作 |
| `--info` | `199 89% 58%` | 提示性信息 |

> 使用规则：语义色只用于状态与数据，不用于装饰；success/warning/danger 均配套 `-soft`（同色 12% 透明）底色用于 Badge。

### 2.4 Agent 角色色（贯穿消息、时间线、Workflow 节点）

| 角色 | Token | 色值 |
| --- | --- | --- |
| Planner | `--agent-planner` | `258 88% 66%`（紫） |
| Executor | `--agent-executor` | `217 91% 62%`（蓝） |

| Replanner | `--agent-replanner` | `189 85% 55%`（青） |

### 2.5 图表色板（Recharts 统一 8 色，按序取用）

`violet #8b5cf6 · blue #3b82f6 · cyan #06b6d4 · emerald #10b981 · amber #f59e0b · rose #f43f5e · fuchsia #d946ef · slate #64748b`

网格线用 `--border` @ 60% 透明；坐标轴文字用 `--foreground-muted` 12px；tooltip 复用 `--surface-elevated` 卡片样式。

## 3. 字体与排版

| 项 | 值 |
| --- | --- |
| 无衬线栈 | `Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`（@fontsource 本地化，中文走系统字体不额外加载） |
| 等宽栈 | `"JetBrains Mono", Consolas, monospace`（代码 Diff、ID、终端输出、KPI 数字） |
| 基准字号 | **14px**（专业工具密度），行高 1.5 |

| 层级 | 字号/行高/字重 | 用途 |
| --- | --- | --- |
| Display | 30 / 36 / 600 tabular-nums | KPI 大数字 |
| Title-L | 20 / 28 / 600 | 页面标题 |
| Title-M | 16 / 24 / 600 | 卡片标题、区块标题 |
| Body | 14 / 22 / 400 | 正文、表格 |
| Secondary | 13 / 20 / 400 | 辅助说明、图例 |
| Caption | 12 / 16 / 500 | 标签、时间戳、Badge、坐标轴 |
| Code | 13 / 20 / 400 mono | Diff、终端、参数 |

规则：标题不使用超大字重堆叠（≤600）；全站禁用斜体强调；数字处一律 `font-variant-numeric: tabular-nums`。

## 4. 间距 · 圆角 · 阴影 · 边框

| Token | 值 | 用途 |
| --- | --- | --- |
| 间距基准 | 4px 栅格（4/8/12/16/20/24/32） | 卡片内边距 16，区块间距 24，页面留白 24（移动端 16） |
| `--radius` | 8px | 按钮、输入框、小卡 |
| radius-lg | 12px | 卡片、弹层 |
| radius-full | 999px | Badge、StatusDot、头像 |
| `--shadow-card` | `0 1px 2px rgb(0 0 0 / 40%)` | 默认卡片（极轻） |
| `--shadow-pop` | `0 8px 24px rgb(0 0 0 / 50%)` | 下拉、弹层、抽屉 |
| 边框 | 1px `--border`；hover 时 `--border-strong` | 不使用 2px 以上边框 |

密度：提供 舒适（默认）/紧凑 两档（`--space-scale: 1 | 0.85`，P2）。

## 5. 组件规范

### 5.1 shadcn/ui 基础组件（按设计系统覆写后使用）

`Button · Input · Textarea · Select · Dialog · Sheet（移动抽屉）· Tabs · Tooltip · DropdownMenu · Table · Badge · Card · Skeleton · Switch · Slider · ScrollArea · Command（⌘K 面板）· Popover · Separator · Toast(Sonner)`

覆写约定：所有组件 radius 统一 8px；`variant` 里新增 `soft-*` 系列（12% 透明底 + 同色文字）用于状态型按钮。

## 6. 动效规范（Framer Motion）

| 项 | 规范 |
| --- | --- |
| 时长 | 微交互 120ms · 进出/布局 180ms · 页面级 240ms；上限 300ms |
| 缓动 | 进场 `easeOut`，退场 `easeIn`，布局 `easeInOut`；**禁止弹簧 overshoot 用于数据/表格** |
| 页面切换 | fade + 4px 上移进入，150~240ms |
| 列表进场 | stagger 30ms/项，仅首屏一次（分页/筛选不做） |
| 状态脉冲 | running 状态 `StatusDot` 2s 循环 opacity 脉冲（唯一允许的循环动画） |
| 数字变化 | KPI 数字用 300ms 计数补间，不弹跳 |
| 面板 | 抽屉/折叠用 width/height 补间；React Flow 节点状态用 CSS transition |
| 禁止 | 循环装饰动画（除 running 脉冲）、3D 翻转、大位移视差、图表 loading 旋转轮 |
| 降级 | 全局尊重 `prefers-reduced-motion`：跳过位移/补间，仅保留 opacity |

## 8. 可访问性基线

- 正文对比度 ≥ 4.5:1；muted 文本只用于辅助信息。
- 焦点环：2px `--primary` @ 50% 透明外环，键盘可达。
- 状态除颜色外必须带文字或图标（色盲安全）。
- 弹层统一 trap focus，`Esc` 关闭；审批卡进入时朗读公告（`aria-live=polite`）。

## 9. Tailwind 实现约定

```
:root { ...上表 HSL 变量... }
tailwind.config → colors: { background:'hsl(var(--background))', ... }
语义别名:  text-primary→--foreground（注意与品牌 primary 区分，
          品牌紫统一用 bg-primary/text-primary-fg，避免混淆，评审时重点检查）
禁止: 组件内写死 hex 色值 / 任意 px 间距(用 4 栅格) / 未注册的自定义阴影
```

所有 token 以「CSS 变量 → tailwind 映射」单向流动；组件层只允许使用 token 别名类，保证未来主题扩展（Light、高对比）零改造成本。
